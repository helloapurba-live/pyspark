# What do these packages do?
# ---------------------------
#
# 1. PySpark: Imagine you have a million transactions. Regular Python would
#    struggle, but PySpark can split the work across multiple computers!
#
# 2. MLflow: Like a lab notebook. It remembers every experiment you run,
#    so you can compare "which model performed best?"
#
# 3. Scikit-learn: Contains many classic ML algorithms. We use it for
#    preprocessing and as a reference.
#
# 4. Matplotlib/Seaborn: Turn boring numbers into beautiful charts that
#    help you understand what's happening.
#
# 5. NLTK: Helps us understand text. For example, it knows that "payment"
#    and "paying" are related words.
#
# How to install?
# ---------------
# Open your terminal and run:
#   pip install -r requirements.txt
#
# If you get errors:
# ------------------
# 1. Make sure Python 3.8+ is installed: python --version
# 2. Upgrade pip: pip install --upgrade pip
# 3. Use a virtual environment (recommended!):
#    python -m venv venv
#    source venv/bin/activate  # On Windows: venv\Scripts\activate
#    pip install -r requirements.txt
